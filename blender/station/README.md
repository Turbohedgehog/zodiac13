# Станция в Blender: как её собрать заново

Полная станция в стиле ретрофутуризма 80-х (светлый металл, только ЭЛТ-мониторы, отделы как в SS13, механики оригинальные).
Октагон 168×132 м, 162 помещения, 235 дверей, 230 шаблонов, 43 091 экземпляр, 748 источников света, 113 точек спавна.
Сводка чисел и состав по видам помещений: `station_meta.json`. Рендеры: `render/`.

## Что где лежит

| Путь | Что |
|---|---|
| `../model_scripts/` | весь код (Python для `bpy`), в репозитории |
| `../export/station_library.blend` | библиотека: коллекция `templates` (230 шаблонов) и 178 материалов с процедурным износом |
| `../export/station_map.json` | карта: комнаты, 43 091 экземпляр (`template`, `at`, `yaw`), точки спавна, лампы, список потолков |
| `../export/station_materials.json` | материалы как данные: цвет, металличность, шероховатость, свечение, признак износа |
| `../export/station_map.blend` | копия готовой сцены |
| `../export/station_models.fbx` | шаблоны в FBX (старый, без процедурных материалов; пересобрать через `station_models.export`) |
| `station_meta.json` | числа и состав |
| `render/*.png` | 10 рендеров интерьеров |

## Пересборка в новой сессии

1. Blender 5.0, аддон BlenderMCP, `../.mcp.json` (см. `../README.md`).
2. Четыре вызова `execute_blender_code`, по одному на стадию (иначе таймаут MCP на 40 тыс. объектов):

```python
import sys; sys.path.insert(0, r"C:\Projects\zodiac13\blender\model_scripts")
import station_build as b
b.stage_geometry()   # шаблоны, полы, стены, двери (~15 с)  -> geometry 37461 rooms 162
b.stage_decor()      # декор по комнатам                    -> decor 41165
b.stage_extras()     # доп. предметы, заброшенное крыло, гермодвери, мелочь, таблички -> total 43091
b.stage_finish()     # потолки, свет по лампам, спавны, экспорт в ../export
```

Числа в комментариях сверены повторной сборкой с нуля. Состояние между вызовами MCP не сохраняется: имена импортируйте заново.
Очистка большой сцены: `bpy.data.batch_remove`, не по одному объекту.

## Из чего состоит код (`model_scripts/`)

- `station_models.py` — `Builder` (примитивы на bmesh), материалы (`material()` сам добавляет процедурный износ), панели стен, двери, окна, полы по отделам.
- `station_items*.py`, `station_small.py` — предметы интерьера (шаблоны `decor_*`).
- `station_scenes.py` — `SceneBuilder`: экземпляры шаблонов как связанные меши (одна копия меша на шаблон), коллекция скрытых шаблонов `templates`.
- `station_layout.py` — движок раскладки и план станции (`ROOMS`, `LINKS`, `SPURS`, `OCTAGON`), сборка стен, дверей, полов, функции декора `d_*`, словарь `DECOR` по виду комнаты.
- `station_fill.py` — подписи (`TITLES`, по-русски), декор шлюзов, тоннелей, тюрьмы и т. д.; `station_extras*.py`, `station_wing.py` (заброшенный сектор, гермодвери) — дополнения.
- `station_finish.py` — потолки, свет, точки спавна, экспорт карты и библиотеки.
- `station_build.py` — запуск стадий.

## Правила раскладки (чтобы не наступить снова)

- Клетка 1 м; в игре клетка 0,25 м. Стена — плита в одну клетку (0,25 м) внутри клетки владельца: выше комната, затем не-коридор, затем меньший индекс (`owns_wall`).
- Дверь ставится на ровном стыке в две клетки двух комнат; на ступенчатой диагонали двери невозможны. Допущенные потерянные связи: `('c1','v4')`, `('mt_s3','cargo_dock')`.
- Контур: октагон `OCTAGON = (-4, 0, 164, 132, 30)` (срез углов 45°); комнаты, где осталось меньше 35% клеток (`MIN_KEEP`), выпадают, их функции переданы соседям.
- Заброшенный сектор `old_*` внутри контура на западе, отделён большим коридором 4 м; временные замены потерянных блоков (`temp_brig`, казармы, морг, вирусология).
- Шлюзы двухзонные: `airlock_pair` = комната со скафандрами (`*_prep`) + камера; прибытие (`arrivals`) на восточном краю.
- Гермодвери: каждые 24 м в коридорах и 20 м в тоннелях плюс линии по меридианам `SEAL_X`. Это рамки, закрывающей механики нет.
- Декор: настенное — спиной к Y=0 и лицом к −Y; стоящее — по центру; стороны N/S/E/W, повороты `FACING_ANGLE`; судья, пастор, столы руководителей смотрят на дверь.
- Стены: один оттенок на ряд, тонкие сквозные горизонтальные полосы и мелкие заклёпки, рельеф не более 1 см (шахматный узор и «гладко» отвергнуты). Трубы и кабели допустимы только в технических коридорах.
- Технические коридоры — сквозной путь из конца в конец; кольцевые тоннели по периметру убраны, они закрывали окна и шлюзы.

## Материалы и свет

- Все материалы Principled; `add_surface_texture` добавляет пятна оттенка, зерно (bump) и на металле полосы в шероховатости. Это ноды Blender: в FBX они не попадают.
- Передача в игру: библиотеку подключить (link/append) и ставить экземпляры из `station_map.json`; материалы по имени из `station_materials.json`. Загрузчик игры (`assimp_loader.cpp`) сейчас читает только диффузную текстуру, цвет и PBR-параметры надо добавить отдельно. Запекание не годится: станция будет собираться из сегментов.
- Свет: по одному источнику на каждую рабочую лампу (трубчатая, маяк, лампа для растений, торшер, настольная, хирургическая); разбитые лампы не светят; в заброшенной зоне слабее (35%) и красноватый. Тени выключены.
- Рендер: EEVEE с трассировкой лучей, небо Nishita с силой 0,2, экспозиция −0,7, 1280×720.

## Точки спавна

`SPAWN_<комната>_<n>`: пустышки в коллекции `spawn_points`, свойства `room` и `kind`, по одной на комнату (две, если клеток ≥ 120), на свободном месте, лицом к ближайшей двери. Есть во всех каютах и отделах; нет в коридорах, тоннелях, технических комнатах, шлюзах, причалах и заброшенной зоне.

## Что не сделано

- Игра не читает материалы из `station_materials.json`; карта не переведена в блоки палитры (`assets/station/blueprints/*.json`).
- Один этаж; второй жилой этаж (мест сейчас 53–57 вместо 80–100) и многоэтажность не начаты.
- Не осмотрены вблизи: старая столовая и лаборатория, угловые технические комнаты, новый причал, казармы, новый морг и вирусология.
- Гермодвери — рамки без механики закрытия.
