# Zodiac 13

[🇷🇺 Русский](README.ru.md) | [🇺🇸 English](README.md)

---

**Zodiac 13** - это онлайн игра на одноимённой станции. Данный проект был вдохновлён **Space Station 13**.
В цели данного проекта ставятся:
- **Высокая производительность**
- **Кроссплатформенность**
- **Трёхмерное окружение**
- **Ролевая система**
- **Низкий порог входа**
- **Модульная архитектура проекта**
- **Лёгкая расширяемость**
- **Физика газов**
- **Строительство/разрушаемость станции**
- **Множество игровых профессий**
- **Квестовая система**
- **Воспроизведение записанных игровых сессий**
- **Удобная модерация игрового процесса**
- **Поддержка скриптовых систем**

Данный проект является хобби, поэтому реализуется в ленивом темпе.
