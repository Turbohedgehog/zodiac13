# Zodiac 13

[🇷🇺 Русский](README.ru.md) | [🇺🇸 English](README.md)

---

**Zodiac 13** is an online game set on a space station of the same name. The project was inspired by **Space Station 13**: its gameplay mechanics are the reference, reworked and simplified along the way, while the code, art, sounds and texts are all our own.

The goals of this project are:

- **High performance**
- **Cross-platform support**
- **3D environment**
- **Role-playing system**
- **Low entry barrier**
- **Modular project architecture**
- **Easy extensibility**
- **Gas physics (atmospherics)**
- **Station construction and destructibility**
- **A wide variety of in-game jobs**
- **Quest system**
- **Replay system for recorded game sessions**
- **Convenient moderation tools**
- **Scripting system support**

This project is a hobby, so it is being developed at a relaxed pace.
